# 배운점
## 로지스틱 회귀
로지스틱 회귀는 KNN 분류 알고리즘 외에 사용할 수 있는 방법으로, 요소의 특성에 따른 선형방정식을 학습하고 이를 시그모이드 함수에 대입에 0과 1 사이의 특정 값을 갖게하여 요소가 각 분류에 속할 확률을 보이는 기법이다.

## 경사하강법
경사하강법이란 손실함수를 최소화시키는 방향으로 선형방정식의 계수를 조정하는 방법이다.

그래서 전체 데이터 중에서 한 개, 일부, 또는 전부를 가지고 경사하강법을 사용해 가장 최적의 선형방정식을 찾아낸다. 전체 데이터셋을 다 쓰면 다시 전체 데이터를 가지고 경사하강법을 진행한다. 이렇게 한 번 도는 과정을 에포크라고 칭한다.

## 과적합
에포크가 지나치게 적다면 모델이 데이터를 적게 학습하여 제대로된 분류가 불가능하고, 에포크가 지나치게 크다면 모델이 너무 데이터에 핏하게 학습하여 새로운 데이터에 대한 예측도가 떨어진다.

일반적으로 소규모 데이터셋(1만 개 미만)은 10~50 에포크, 중간 정도의 규모(10만 개 미만)은 50~200 에포크, 대규모(10만 개 이상)은 최대 500 이상의 에포크가 적정하다고한다.

그래서 적정한 에포크를 찾는 것도 좋지만 인공지능 학습 시 정확도가 증가하지 않거나 오히려 감소하고 있는 경우 이를 감지에 조기에 학습을 종료하는 조기 종료 방법도 있다.

# 느낀점
1~2주차 때 KNN을 다루면서 요소의 특성이 늘어나게되면 KNN 분류를 사용하기 부적합한 환경이 될 것이라고 생각했는데 로지스틱 회귀를 통해서 KNN의 단점을 예방하면서도 정확도 높은 데이터 분류모델을 학습할 수 있었다.

수치해석 때 근을 찾는 기법 몇 개를 배웠던 적이 있는데 경사하강법에서도 써먹어볼 수 있지 않을까도 생각해보았다. AI 스터디를 들으면서 수치해석이야말로 AI학습과 가장 밀접한 분야가 아닐까 생각들었다.

요즘에는 엘라스틱서치에 관심이 생겨서 공부해볼까 생각 중인데, 엘라스틱서치와 로지스틱회귀를 적절히 사용하면 상호 보완용도로도 사용할 수 있지 않을까 생각해보게되었다. 물론 로지스틱회귀도 더 공부해야하고 엘라스틱서치도 공부해야하지만 ES로 여러 개 데이터를 가져온 후 로지스틱 회귀로 더 정교하게 가려내는 방향으로 갈 수 있지 않을까 생각해보았다.
